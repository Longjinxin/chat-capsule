# 沟通胶囊（Communication Capsule）

## 1. 产品定位

沟通胶囊是一款 Windows 桌面端、单用户、本地运行的沟通效率工具。

核心目标：让用户像使用输入法一样，在不离开当前聊天软件、不打断工作流的情况下，快速保存、搜索并将常用话术插入到任意聊天输入框。

典型用户：招聘人员，以及未来可能使用大量重复沟通内容的销售、HR、客服、BD
等人员。

## 2. 核心体验

> 搜索 → 找到话术 → 拖拽/双击 → 进入当前输入框 → 用户二次编辑 → 手动发送

产品不是招聘平台，不负责候选人管理，不自动发送消息，也不需要接入 Boss
直聘、LinkedIn、微信等平台的账号。

## 3. V1 产品形态

-   Windows 桌面应用
-   安装包方式安装
-   常驻后台
-   右上角悬浮胶囊入口
-   一个核心界面，尽量不跳转、不多窗口
-   本地存储，不需要账号和服务器
-   支持全局快捷键
-   支持鼠标与键盘操作

## 4. V1 核心功能

### 4.1 唤起沟通胶囊

通过自定义全局快捷键唤起/聚焦悬浮窗口。

### 4.2 新增话术

用户在任意应用中选中一段文字，通过自定义快捷键将选中文本保存为一个新的沟通胶囊。

V1 数据最小化： - 正文 - 颜色 - 创建时间/更新时间等系统字段

不要求用户填写标题、标签或分类。

### 4.3 搜索

直接搜索话术正文全文。

例如输入： - 产品经理 - 公司介绍 - AI - 海外上市

即可返回正文中匹配的胶囊。

默认展示 5 条结果。

### 4.4 话术预览

鼠标悬停在胶囊上时，展示该胶囊的完整内容。

### 4.5 插入话术

支持： 1. 将胶囊拖拽到目标聊天输入框 2. 双击胶囊作为拖拽失败时的备用操作

插入只负责把文本放入输入框，不自动发送。

用户可以继续编辑后自行发送。

### 4.6 替换话术

用户选中新版本文字，通过自定义快捷键进入"替换胶囊"流程： 1. 选中文字 2.
唤起替换功能 3. 搜索旧胶囊 4. 选择旧胶囊 5. 用新文字替换原正文

### 4.7 编辑

可以直接编辑已有胶囊正文。

### 4.8 删除

可以删除已有胶囊。

### 4.9 颜色

每个胶囊允许设置一种颜色。

颜色只是视觉识别，不承担正式标签/分类系统。

### 4.10 新增按钮

主界面提供"+"按钮，可以直接新增胶囊。

## 5. 快捷键

所有核心快捷键必须支持用户自定义。

建议提供默认值，但开发时不要把默认组合设计成不可修改。

建议默认： - 唤起/聚焦：Alt + Space - 新增：Ctrl + Shift + C -
替换：Ctrl + Shift + R

如果快捷键已被系统或其他软件占用，应提示冲突并允许重新设置。

## 6. 初始交互参数

-   默认悬浮位置：屏幕右上角
-   搜索结果：默认 5 条
-   悬停：展示完整正文
-   插入：拖拽优先，双击备用
-   发送：永远由用户手动发送
-   排序：V1 不提供用户手动拖拉排序
-   编辑：支持
-   删除：支持
-   颜色修改：保持极简，可在编辑入口中支持，但不增加复杂颜色管理
-   标签：不支持
-   变量：不支持
-   自动替换候选人姓名/岗位等：不支持
-   团队共享：不支持
-   云端同步：不支持
-   账号体系：不支持

## 7. UI/UX 参考方向

产品视觉与交互不应模仿传统招聘系统，而应参考：

-   Windows 输入法：轻量、常驻、快速唤起
-   Raycast：搜索优先、键盘驱动、高密度结果
-   PowerToys Run：全局唤起、快速搜索
-   Notion / Linear：简洁、层级清晰、减少干扰
-   Sticky Notes / 便利贴类产品：轻量内容卡片与颜色识别

核心原则： - 一个核心界面 - 不打断当前工作 - 高频操作尽量两步以内 -
搜索优先 - 键盘和鼠标均可完成核心流程 - 信息密度高，但视觉保持轻盈 -
胶囊这个产品名称应该在视觉形态上得到体现

## 8. V1 明确不做

-   自动发送消息
-   自动登录第三方平台
-   第三方平台账号管理
-   候选人管理
-   ATS
-   CRM
-   团队共享
-   云同步
-   AI 自动生成话术
-   AI 改写
-   标签系统
-   复杂分类
-   变量系统
-   自动替换变量
-   消息统计
-   用户行为分析

## 9. 成功标准

一个第一次使用的招聘人员，在没有培训的情况下，应能够在 1 分钟内完成：

1.  唤起沟通胶囊
2.  新增一条话术
3.  搜索话术
4.  将话术插入聊天输入框
5.  编辑后手动发送
6.  编辑/删除一条已有话术

如果需要阅读长篇说明才能完成上述操作，则说明 UI/UX 仍需简化。

## 10. 迭代变更汇总（按实际开发记录整理）

### 产品名称

- 产品名称已统一为“聊天胶囊”。

### 当前交互形态

1. 收起态为 64×32 深色横向胶囊，常驻屏幕右上角。
2. 点击或双击胶囊打开主界面。
3. 主界面为搜索框 + 话术列表。
4. 话术单行展示，悬停查看完整内容。
5. 单击话术插入到当前前台输入框；拖拽话术仍可作为 UI 交互。
6. 双击编辑已取消，改为编辑按钮；删除有确认。
7. 排序拖拽按钮常显，编辑/删除按钮悬停显示。
8. 展开面板可自由调整大小，胶囊高度不变，宽度跟随面板。

### 插入机制变化

- 跨应用文本插入从“依赖目标页面接受拖拽”调整为“Clipboard + Ctrl+V”。
- 插入前保存剪贴板，插入后恢复剪贴板。
- 通过持续跟踪 Windows 前台窗口决定插入目标，不针对微信、Slack、Boss 直聘写死逻辑。

### 已知待处理事项

- 拖动位置记忆曾造成窗口异常，当前先强制默认右上角；位置记忆方案待重新设计。
- 微信、Slack、Boss 直聘真实环境验收以人工实测为准。
