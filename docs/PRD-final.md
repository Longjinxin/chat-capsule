## 1. 产品概述

### 1.1 产品定位

**聊天胶囊**是一款 **Windows 桌面端、单用户、本地运行** 的沟通效率工具。

核心价值：像「输入法」一样，让用户**不离开当前聊天软件、不打断工作流**，快速完成【保存 → 搜索 → 插入】常用话术到任意聊天输入框。

### 1.2 目标用户

| 用户 | 说明 |
| --- | --- |
| 招聘人员（V1 主用户） | 在 Boss 直聘 / LinkedIn / 猎聘 / 微信 / 企业微信 / 钉钉等重复发送相似内容 |
| 未来潜在用户 | 销售、HR、客服、BD 等大量重复沟通内容的岗位 |

### 1.3 核心场景

- 招聘人员与候选人沟通、与内部业务方沟通
- 重复发送公司介绍 / 岗位介绍 / 邀约内容 / 流程说明

### 1.4 三条铁律（不可违背）

1. **不打断当前工作流** —— 常驻、轻量、快速唤起，用户始终停留在原聊天软件内。
2. **不自动发送** —— 永远由用户手动发送，产品只负责把文本放进输入框。
3. **本地优先** —— 单机、无账号、无云、不采集聊天内容，只在用户明确触发时处理选中文本 / 输入框内容。

### 1.5 产品形态

- Windows 桌面应用（Electron + TypeScript + React + SQLite + Vite）
- 常驻后台，右上角悬浮胶囊入口，无系统标题栏、无任务栏入口
- 单核心界面，尽量不跳转、不多窗口
- 本地存储，不需要账号和服务器
- 支持全局快捷键（可自定义）
- 鼠标 + 键盘均可完成核心流程

## 2. 用户故事

| 编号 | 角色 | 需求 | 收益 |
| --- | --- | --- | --- |
| US-01 | 招聘人员 | 看到值得复用的话术时，直接选中文字并通过快捷键保存，不用切换到其他工具 | 零切换成本沉淀话术 |

| US-06 | 招聘人员 | 编辑、删除、手动排序已保存的话术 | 话术库可维护 |

## 3. 功能需求池

### 3.1 P0（本次必做，硬性范围）

#### P0-1 保存话术（界面 "+"）

- **功能**：主界面提供 "+" 按钮进入新增状态，输入正文并保存为胶囊。
- **交互细节**：打开新增输入状态 → 用户输入正文 → 保存 → 列表实时出现新胶囊。
- **验收标准**：
  - 点击 "+" 可进入新增输入状态；
  - 输入正文保存后，新胶囊出现在列表中；
  - 空正文不可保存（给出提示或禁用保存）。

#### P0-2 保存话术（全局快捷键抓取选中文本）

- **功能**：全局快捷键抓取当前系统中用户选中的文本，直接创建新胶囊。
- **交互细节**：触发快捷键 → 保存当前剪贴板 → 模拟 Ctrl+C 获取选中文本 → 读剪贴板 → 恢复原剪贴板 → 创建胶囊 → 显示约 1 秒轻量成功提示。
- **验收标准**：
  - 在任意应用选中文本，按快捷键后新胶囊出现；
  - 未选中文本时不创建空胶囊，并给出提示；
  - 操作完成后用户原剪贴板内容被恢复。

#### P0-3 搜索话术

- **功能**：对胶囊正文全文搜索，实时返回结果，命中关键词高亮，滚动查看。
- **交互细节**：
  - 搜索框为核心，面板打开后自动聚焦；
  - 全文搜索，无标题、无标签；
  - **默认一次性加载更多（内部 limit 上限 200）**，界面通过右侧滚动条滚动查看，**无「5 条」「7/20/50」下拉**；
  - UI 固定展示约 7 条胶囊高度，右侧滚动条常驻；
  - 命中关键词在正文中高亮；
  - 搜索框有内容时显示一键清空按钮；
  - 无结果时显示简短提示。
- **验收标准**：
  - 输入关键词，结果实时出现；
  - 命中词在正文中高亮；
  - 列表可滚动查看，无条数下拉框；
  - 清空按钮可一键清空搜索框。

#### P0-4 插入话术（单击 / 拖拽，不自动发送）

- **功能**：把话术写入当前目标输入框，不自动发送。
- **交互细节**：
  - **单击胶囊 = 可靠插入路径**（走统一 InsertEngine，Clipboard + Ctrl+V 注入）；
  - **拖拽仅作 UI 交互兜底**，最终注入同样走 InsertEngine；
  - **双击已不再用于编辑**；
  - 插入前保存剪贴板快照 → 写入文本 → 隐藏/失焦聊天胶囊 → 恢复目标前台窗口 → 模拟 Ctrl+V → 恢复原剪贴板；
  - 目标窗口跟随当前真实前台窗口（TargetWindowTracker），**不写死**微信/Slack/Boss 直聘。
- **验收标准**：
  - 单击胶囊，文本进入当前前台输入框；
  - 拖拽胶囊，文本同样进入输入框；
  - 插入后**不自动发送**，用户可继续编辑；
  - 插入后原剪贴板被恢复；
  - 目标窗口不会指向聊天胶囊自身窗口。

#### P0-5 选中文字保存 + 替换（替换旧话术流程）

- **功能**：全局快捷键抓取当前选中文本，进入替换流程，用新文本更新旧胶囊正文。
- **交互细节**：
  1. 用户选中新文字 → 按替换快捷键；
  2. 进入替换模式，搜索框自动聚焦；
  3. 搜索并选择目标旧胶囊；
  4. 用当前选中文字更新该胶囊正文，**保留其颜色**；
  5. 显示短暂反馈。
- **验收标准**：
  - 选中新文字 → 按替换快捷键 → 搜索旧胶囊 → 选择 → 旧胶囊正文被替换为新文字；
  - 替换后胶囊颜色不变；
  - 替换后搜索结果实时反映新内容。

### 3.2 P1（应做）

#### P1-1 编辑（卡片内完成）

- **功能**：编辑已有胶囊正文。
- **交互细节**：**编辑按钮仅在 hover 胶囊时显示**；编辑在**卡片内**完成，不跳转独立管理页；不提供富文本。
- **验收标准**：hover 出现编辑按钮 → 进入编辑 → 修改正文 → 保存 → 结果实时展示新内容。

#### P1-2 删除（带确认）

- **功能**：删除已有胶囊。
- **交互细节**：**删除按钮仅在 hover 胶囊时显示**；点击后弹出轻量确认（如「删除这条聊天话术？」）；确认后删除；V1 无回收站。
- **验收标准**：hover 出现删除按钮 → 点击 → 确认 → 胶囊消失。

#### P1-3 手动排序（sort_order）

- **功能**：支持手动拖拽排序。
- **交互细节**：最右侧**拖拽按钮始终显示**，按住可上下拖动，拖动过程中实时调整顺序，松开后保存（写 `sort_order`）。
- **验收标准**：拖拽后顺序改变；重启后顺序保持。

#### P1-4 快捷键自定义设置

- **功能**：所有核心快捷键可自定义。
- **交互细节**：设置页提供唤起 / 新增 / 替换 快捷键修改；检测冲突并提示，允许重新设置。
- **验收标准**：修改快捷键后即时生效；冲突有提示。

#### P1-5 面板尺寸记忆

- **功能**：记忆展开面板最后调整的尺寸。
- **交互细节**：面板可自由调整大小，右下角缩放把手，最小 280×240；收起后再次打开恢复最后一次尺寸。
- **验收标准**：调整尺寸 → 收起 → 再打开 → 尺寸保持。

### 3.3 P2（本次可不实现）

- 开机启动（设置项）
- 多显示器 / 位置记忆（当前已强制默认右上角，恢复策略待重新设计）
- 安装包（electron-builder，Windows x64，.exe）
- 自动更新
- 系统托盘（显示/隐藏、设置、退出）

> 注：P1/P2 中「系统托盘」与「开机启动」在旧文档属建议能力，本次基线列为 P2，可按需取舍。

## 4. 数据模型

### 4.1 Capsule（胶囊）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY | 主键 |
| content | TEXT NOT NULL | 话术正文 |
| color | TEXT NOT NULL | 颜色（视觉识别，非分类/标签） |
| sort_order | INTEGER | 手动排序序号（旧库启动时自动迁移补全） |
| created_at | INTEGER NOT NULL | 创建时间（系统字段） |
| updated_at | INTEGER NOT NULL | 更新时间（系统字段） |

列表返回顺序：`ORDER BY sort_order ASC, id ASC`。

### 4.2 Settings（设置，key-value）

| key | 说明 |
| --- | --- |
| global_hotkey_open | 唤起/聚焦快捷键 |
| global_hotkey_add | 新增（抓取选中文本）快捷键 |
| global_hotkey_replace | 替换快捷键 |
| always_on_top | 是否始终置顶 |
| launch_on_startup | 是否开机启动（P2） |
| window_position | 窗口位置（**当前强制默认右上角，位置恢复策略待重新设计**） |

> 面板尺寸记忆使用 `localStorage.capsule_panel_size`；收起胶囊位置曾用 `localStorage.capsule_position`（当前已知异常，先强制默认右上角）。

## 6. UI / UX 关键规格

### 6.1 收起态胶囊

| 项 | 规格 |
| --- | --- |
| 尺寸 | 64 × 32 |
| 圆角 | 16px |
| 背景 | #1E1F23 |
| 左侧标识 | 20×20 橙色圆形 #FFB357，内部白色聊天气泡 SVG（**不使用 Emoji**） |
| 右侧 | 三个 3×3 白色圆点，间距约 4px，表达「可展开」 |
| 阴影 | `0 2px 12px rgba(0,0,0,0.20)`，无明显边框 |
| 位置 | 默认右上角，右/上边距 20px，始终置顶，无系统标题栏、无任务栏入口 |
| Hover | 不放大，仅轻微降低不透明度；按下 `scale(0.95)`，120ms ease-out |

**Tooltip**：悬停约 300ms 后，在胶囊下方显示「打开聊天胶囊」（背景 #1E1F23、透明度 90%、白色 14px、圆角 8px、6px 箭头、间隔 8px、居中）。打开面板后 Tooltip 必须消失。

**交互**：单击/双击均打开主界面；右键菜单：打开聊天胶囊、置顶/取消置顶、设置、退出。

### 6.2 展开面板

| 项 | 规格 |
| --- | --- |
| 结构 | 搜索框（核心）+ 话术列表 |
| 尺寸 | 可自由调整，右下角缩放把手，最小 280×240 |
| 调整行为 | 胶囊高度不变，胶囊宽度随面板宽度变化 |
| 列表高度 | 固定展示约 7 条胶囊高度，右侧滚动条常驻，可向下滚动查看更多 |
| 尺寸记忆 | 记住最后尺寸，收起后再次打开恢复 |

### 6.3 话术卡片

- 圆角矩形、小尺寸、左侧颜色标识、正文单行展示；
- 完整内容通过**胶囊外浮层**查看，不改变胶囊自身大小；
- 悬停浮层位于胶囊**下方、向左缩进两个文字宽度**，浮层字号比胶囊正文小两号后再调大一号；
- 命中关键词在正文中高亮。

### 6.4 Hover 浮层（操作按钮）

- 排序拖拽按钮：**始终显示**，位于最右侧；
- 编辑按钮、删除按钮：**仅在 hover 胶囊时显示**，位于拖拽按钮前方；
- 双击编辑已取消；编辑在卡片内完成；删除有确认。

### 6.5 空状态

首次安装 / 无数据时：

> 「还没有聊天话术」
> 「选中文字后按新增快捷键，即可保存。」
> （提供 "+ 新增"）

### 6.6 无结果态

> 「没有找到相关话术」
> （提供 "+ 新增一条"）

### 6.7 成功提示文案

- 新增 / 替换成功后，显示约 1 秒轻量提示（**非大弹窗**）：
  - 保存成功：`已加入聊天胶囊`
  - 删除确认：`删除这条聊天话术？`

## 7. 权限与隐私

| 原则 | 说明 |
| --- | --- |
| 本地优先 | 数据仅保存在本机 SQLite，无服务器、无账号 |
| 不上传 | 不上传用户话术、不发送分析数据 |
| 不采集 | 不采集聊天记录、不读取第三方聊天软件聊天内容作为产品数据 |
| 不接入账号 | 不接入 Boss 直聘 / LinkedIn / 微信等第三方平台账号 |
| 仅在明确触发时处理 | 仅在用户明确触发保存/替换/插入时，才处理选中文本或目标输入框内容 |
| 剪贴板不留痕 | 抓取选中文本、插入文本前后均恢复用户原剪贴板 |

## 附录 A：关键实现锚点（供架构/开发对齐）

- **InsertEngine**：统一执行 Clipboard + Ctrl+V 注入，六步流程（保存剪贴板 → 写文本 → 隐藏/失焦胶囊 → 恢复目标窗口 → Ctrl+V → 恢复剪贴板）。
- **TargetWindowTracker**：持续监听前台窗口，记录最近一个「非胶囊自身窗口」，结构含 hwnd / processId / processName / title / timestamp；胶囊自身及 Tooltip 窗口不更新目标。
- **数据操作**：新增 `reorderCapsules`、`deleteCapsule`；列表按 `sort_order ASC, id ASC` 返回；旧库启动时自动迁移补 `sort_order`。
- **窗口管理**：收起态与展开态切换时动态控制 `resizable`、`minimumSize`；优先 `showInactive()` + `focusable:false` 降低抢焦点风险。
